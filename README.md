# STATUS SEAT PLAN A320(05) · ตรวจสภาพที่นั่งและ Monitor

หน้าเว็บให้ฝ่ายการช่าง/ฝ่ายสื่อสารบันทึกสภาพที่นั่งและ Monitor ของเครื่อง A320(05) (76 ที่นั่ง, Monitor 21 จอ)
ข้อมูลทุกครั้งที่กด **SAVE** จะบันทึกลง Google Sheet **Seat Plan 320(05) (For Admin)** โดยตรง
และเพิ่มบรรทัดในแท็บ **ประวัติการแก้ไข**

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บ (ผังที่นั่ง, ปุ่ม CLEAR / PREVIEW / SAVE / EXPORT TO PDF / EXPORT TO EXCEL) |
| `layout.js` | ผังที่นั่งในชีท (ตำแหน่งช่อง, ชื่อที่นั่ง/จอ, สูตรสรุป) ใช้ร่วมกันระหว่าง EXPORT TO EXCEL และ Apps Script |
| `export-excel.js` | สร้างไฟล์ EXPORT TO EXCEL 4 แผ่นงาน: ผังที่นั่ง, รวมข้อขัดข้องคงค้าง, ทุกที่นั่ง และ Monitor, ประวัติการแก้ไข |
| `config.js` | ใส่ URL ของ Apps Script Web App |
| `apps-script/Code.gs` | โค้ดที่วางใน Apps Script ของ Google Sheet: สร้างแท็บในชีท, อ่าน/บันทึกข้อมูลให้หน้าเว็บ และเก็บประวัติเมื่อแก้ในชีทโดยตรง |

## การติดตั้ง (ทำครั้งเดียว)

### 1. เปิดหน้าเว็บด้วย GitHub Pages
1. ใน repo นี้ ไปที่ **Settings > Pages**
2. Source เลือก **Deploy from a branch**, Branch เลือก **main** และ **/ (root)** แล้วกด Save
3. รอ 1–2 นาที หน้าเว็บจะอยู่ที่ `https://rtaf602.github.io/a320-05_seatplan/`

### 2. ติดตั้ง Apps Script ใน Google Sheet
1. เปิด Google Sheet **Seat Plan 320(05) (For Admin)** > **ส่วนขยาย (Extensions) > Apps Script**
2. ลบโค้ดเดิมทั้งหมดใน `Code.gs` แล้ววางโค้ดจาก `apps-script/Code.gs`
3. ถ้าต้องการรหัส ให้แก้บรรทัด `WRITE_PIN` / `ADMIN_PIN` (อยู่ในส่วน "ตั้งค่า" ช่วงกลางไฟล์):
   - `WRITE_PIN` รหัสที่ช่างต้องใส่ตอนเปิดหน้าเว็บและก่อน SAVE เช่น `'6020'` (เว้นว่าง = ไม่ต้องใช้รหัส)
   - `ADMIN_PIN` รหัสสำหรับปุ่ม "ล้างข้อมูลทั้งหมด" บนเว็บ (เว้นว่าง = ไม่แสดงปุ่มนี้)
4. กด **บันทึก (Save)**
5. **สร้างแท็บในชีท:** เลือกฟังก์ชัน **setupSheet** ในช่องด้านบน แล้วกด **Run (เรียกใช้)** และกดอนุญาตสิทธิ์ด้วยบัญชีเจ้าของชีท
   ระบบจะสร้างแท็บ **ผังที่นั่ง**, **รวมข้อขัดข้องคงค้าง**, **ทุกที่นั่ง และ Monitor**, **ประวัติการแก้ไข** และลบแท็บว่าง Sheet1
6. กด **Deploy > New deployment** > ไอคอนเฟือง เลือก **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
7. กด **Deploy** แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

### 3. เชื่อมหน้าเว็บกับชีท
แก้ไฟล์ `config.js` ใน GitHub ใส่ URL จากข้อ 2.7:

```js
API_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec',
```

กด Commit แล้วรีเฟรชหน้าเว็บ แถบด้านบนจะขึ้น "ข้อมูลจาก Google Sheet"

## เมื่อแก้โค้ด Apps Script ภายหลัง
กด **Deploy > Manage deployments >** ไอคอนดินสอ > Version เลือก **New version** > Deploy
URL เดิมใช้ต่อได้ ไม่ต้องแก้ `config.js`

ถ้าแก้ผังที่นั่งใน `layout.js` ให้รัน `tools/build-code-gs.sh` เพื่อสร้าง `apps-script/Code.gs` ใหม่
แล้ววางโค้ดใหม่ใน Apps Script และรัน **setupSheet** อีกครั้ง (สภาพและหมายเหตุเดิมของทุกที่นั่งยังอยู่ ประวัติไม่หาย)

## การทำงาน
- หน้าเว็บอ่าน/บันทึกที่แท็บ "ผังที่นั่ง" และดึงข้อมูลใหม่ทุก 30 วินาที
- แต่ละที่นั่ง/จอในชีทมี 3 ช่องเรียงลงมา: ชื่อ (เช่น `10A`, `OVHD Monitor 12" · หน้า 10A-10C`) / สภาพ (dropdown) / NOTE
  Apps Script หาตำแหน่งจากชื่อ จึงแทรกแถวหรือขยับผังได้ ขอแค่ไม่แก้ข้อความชื่อ
- SAVE: เขียนสภาพที่นั่ง, Monitor และหมายเหตุลงช่องในชีท, อัปเดตช่อง SAVE ล่าสุดที่หัวชีท และเพิ่มประวัติ
  (ช่องอีเมลจะเป็น "หน้าเว็บ" และช่องผู้ตรวจเป็นชื่อที่ใส่บนเว็บ)
- แก้ในชีทโดยตรงก็บันทึกประวัติเช่นกัน และหน้าเว็บจะเห็นค่าใหม่ในรอบดึงข้อมูลถัดไป
- ถ้ายังไม่ได้ใส่ `API_URL` หน้าเว็บยังเปิดดูและแก้ได้ แต่ SAVE ไม่ได้

## ข้อควรรู้ด้านความปลอดภัย
- Web App ตั้งเป็น "Anyone" เพื่อให้ช่างใช้ได้โดยไม่ต้องล็อกอิน Google ใครที่ได้ URL ก็อ่าน/บันทึกได้ จึงแนะนำให้ตั้ง `WRITE_PIN`
- เมื่อตั้ง `WRITE_PIN` หน้าเว็บจะถามรหัสทุกครั้งที่เปิดหน้า และทุกครั้งที่กด SAVE โดยไม่จำรหัสไว้ในเครื่อง และ URL ของ Apps Script จะไม่ส่งข้อมูลให้ถ้าไม่มีรหัส
- Repo นี้เป็น public ห้ามใส่รหัสลงใน `config.js` หรือไฟล์ใดใน repo ให้ตั้งรหัสเฉพาะใน Apps Script
- ประวัติการแก้ไขอยู่ในชีท ผู้มีสิทธิ์แก้ไขชีทลบได้ ควรล็อกแท็บ "ประวัติการแก้ไข" ด้วย Protect sheet ให้เฉพาะ Admin
